title: "Device sharing with AI agents & more reliable builds"
---

- **Device sharing with AI agents**: Radon now shares its booted devices with [Argent](https://argent.swmansion.com/), so an agent driving your app attaches to the simulator you are looking at instead of booting a second one. Agents can use screenshots, gestures, pasting text, the accessibility tree, native profiler and the native view hierarchy through the connection Radon already owns.

- [**Expo Prebuild no longer overwrites native directories you committed**](/docs/guides/configuration#other-settings): Radon skips Prebuild when git tracks the `ios` or `android` directory and the panel offers to save your preference to the launch configuration in one click. Set `usePrebuild` yourself to force either behaviour.

- **Smarter Expo Go detection**: Radon now checks your dependencies before choosing Expo Go. An app using native modules that Expo Go does not ship gets a development build instead of a crash on startup, with a warning naming the packages. `--dev-client` and `--go` in `expoStartArgs` or your `start` script are now honoured.

- **Dependencies are installed on every path to a build**: Installing `node_modules` is now part of the build pipeline, so _Retry_ installs dependencies instead of building without them and CocoaPods failures say when missing dependencies are the real cause.

- Fixed Expo apps configured with `app.config.ts` (and the other Expo config filenames) being treated as bare React Native, so config plugins never ran.
- Fixed deep links on iOS being withheld behind an `Open in "App"?` confirmation instead of reaching the app.
- Fixed the Redux DevTools panel rendering nothing at all.
- Fixed nvm never being used for project commands when the project has no `.nvmrc`.
- Fixed _Retry_ being unable to recover a session that failed early in start-up and the real error being replaced by an internal one.
- Fixed the React Profiler silently doing nothing when a session recorded no re-renders; it now says so.
- Fixed a failed `node_modules` install being reported as success and surfacing much later as a build error.
- Fixed lost and stuck keystrokes when typing on a remotely streamed device.
- Fixed a crash on simulator server shutdown, along with several video pipeline memory ownership bugs.
- Fixed a simulator server outliving its own stream listener and answering every connection with a reset.
