- **Device sharing with AI agents**: Radon now shares its booted devices with <a href="https://argent.swmansion.com/" target="_blank">Argent</a>, so an agent driving your app attaches to the simulator you are looking at instead of booting a second one. Use all your favorite Radon inspection tools when something needs your attention, while letting Argent automate everything else.

</video>

- **Better compatibility with app development setups**: Radon now handles more project configurations out of the box. It [skips Expo Prebuild](/docs/guides/configuration#other-settings) when the `ios` or `android` directory is tracked by git, so your files are never overwritten and offers to save that choice to the launch configuration in one click. Radon picks between Expo Go and a development build based on your dependencies and honours `--dev-client` and `--go` from `expoStartArgs` or your `start` script. Installing `node_modules` is now part of the build pipeline, so every path to a build goes through it.

- Fixed Expo apps configured with `app.config.ts` (and the other Expo config filenames) being treated as bare React Native, so config plugins never ran.
- Fixed deep links on iOS being withheld behind an `Open in "App"?` confirmation instead of reaching the app.
- Fixed the Redux DevTools panel rendering nothing at all.
- Fixed nvm never being used for project commands when the project has no `.nvmrc`.
- Fixed _Retry_ being unable to recover a session that failed early in start-up and the real error being replaced by an internal one.
- Fixed the React Profiler silently doing nothing when a session recorded no re-renders; it now says so.
- Fixed a failed `node_modules` install being reported as success and surfacing much later as a build error.
- Fixed _Retry_ building against an empty `node_modules` after a failed dependency install and CocoaPods errors not naming missing dependencies as the real cause.
- Fixed lost and stuck keystrokes when typing on a remotely streamed device.
- Fixed a crash on simulator server shutdown, along with several video pipeline memory ownership bugs.
- Fixed a simulator server outliving its own stream listener and answering every connection with a reset.
