- [**Richer inspected component context in AI chat**](/docs/features/element-inspector#add-inspected-components-to-chat-context): Every entry in the right-click component list now has its own _Add to AI chat_ icon. Radon IDE takes a snapshot of that component (its name, dimensions, props, state, stack of ancestor components) and attaches it to the chat context.

</video>

- [**Fix runtime errors in AI chat**](/docs/features/debugging-and-logging#handling-runtime-errors): Whenever a runtime error occurs, a dialog appears above the device offering two actions. _Copy error_ copies the full error message and stack trace to your clipboard, while _Fix in chat_ sends them as a context to AI chat, so you can go from a red screen to a fix without leaving the editor.

- **React Native 0.86 and 0.87 support**

- **Expo SDK 56 and 57 support**

- **Xcode 27 support**

- The Network Inspector no longer discards collected logs when the inspector is disabled and re-enabled.
- Fixed `Set-Cookie` response headers not being propagated to the shared cookie storage.
- Fixed a missing `Content-Type` header in the Android Network Inspector when it can be inferred from the request body.
- Fixed source maps resolving to the wrong file in npm workspaces monorepos.
- Fixed a race condition that could leave the AI chat with an empty `radon-mcp` tool list.
- Fixed an `ENOENT` error when fingerprinting Expo config plugins written in TypeScript.
