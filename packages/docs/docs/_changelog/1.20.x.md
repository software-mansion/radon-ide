---

- **iPhone Duo support**: Radon now supports the foldable iPhone Duo simulator from Xcode 27.1. Fold and unfold it with the buttons in the bottom bar or hold <kbd>⌥</kbd> to pick any hinge angle. All of Radon's tools work on both screens.

- **React Native 0.88 support**

- **Expo SDK 58 support**

- **iOS 27 `UIScene` lifecycle warning**: Apps built with Xcode 27 crash on launch on iOS 27 unless they use the `UIScene` lifecycle. Radon now warns you before launching such an app and links to Expo's migration guide.

- [**View Hierarchy stays up to date**](/docs/features/view-hierarchy-inspector): After the device rotates or the app reloads, the View Hierarchy refreshes itself. On large view hierarchy changes, it may stop updating automatically to prevent long UI thread pauses. In that case, you may refresh it manually with the _Refresh_ button.

- The device preview now follows rotations made by AI agents through <a href="https://argent.swmansion.com/" target="_blank">Argent</a>.
- A simulator that gets stuck while booting is now restarted automatically.
- The Android emulator no longer steals focus from your editor when it boots.
- Fixed Expo Go running React Native 0.87 hanging on launch on iOS.
- Fixed CPU profiles not resolving to source files in some cases.
- Fixed Radon's orientation detection lagging one rotation behind in Expo Go on iOS.
- Fixed Radon waiting forever on Expo Go 56 and 57 for Android, which cannot be debugged. Radon now explains the problem and suggests `expo-dev-client`.
- Fixed mouse-wheel scrolling going the wrong way on rotated devices.
- Fixed the app crashing on launch after switching between Radon versions on the same iOS simulator.
- Fixed the View Hierarchy picker selecting UIKit's floating bar overlay on iOS 27 instead of the tapped view.
- Fixed build errors being hidden behind the _Expo Prebuild skipped_ notice.
- Fixed bare React Native apps with an `app.json` being treated as Expo Go projects.
- Fixed new Android emulators timing out on their first boot and emulators failing to start after an interrupted first boot.
- Fixed deleting or switching away from a booting device taking up to a minute.
- Radon now skips the Expo dev menu onboarding sheet on iOS, as it already did on Android.
