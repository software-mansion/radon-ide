- [**Native View Hierarchy Inspector for iOS**](/docs/features/view-hierarchy-inspector): A new _View Hierarchy_ tab in the bottom panel lets you browse the native UI tree of your iOS app. Hover over a node to highlight the corresponding element on the device, use the element picker to jump to a node by tapping on the simulator, and hit _Refresh_ to reload the tree after UI changes.

- [**Android Network Inspector**](/docs/features/network-inspector): Following the native network traffic support introduced for iOS in [1.16.0](/changelog/1.16.x), the Network Inspector on Android now also captures requests from native components and libraries, including the `Image` component.

- [**Clipboard synchronization**](/docs/features/device-settings): Radon now automatically syncs the clipboard between your computer and the connected device. Copy on the device, paste on the host — and vice versa. Clipboard sync can be toggled off in the Device Settings dropdown.

- **React Native 0.85 support**

- **Rebuild App** reload action: A new _Rebuild App_ option sits between _Reboot Device_ and _Clean Rebuild_ in the reload menu. It reboots the device and forces a fresh native build while keeping incremental compilation, so you skip the cache without a full clean.

- **Per-platform Metro port overrides**: Launch configurations now accept `ios.metroPort` and `android.metroPort` to set a custom Metro port for a specific platform only.

- **Element Inspector now shows dimensions in dp and px**: The Element Inspector tooltip displays sizes in both density-independent pixels (matching your React Native styles) and physical pixels, so no manual conversion is needed.

- Fixed a connection error (`ENOENT: no such file or directory`) that prevented `radon-mcp` from connecting when the MCP server had not yet started.
- Fixed an issue with loading newer Expo Go apps.
- Fixed the Network Inspector hanging on iOS due to an unclosed HTTP body stream.
- Fixed the debugger disconnecting after a font scale change on Android Expo apps.
- The Network table now auto-scrolls to the latest request when you are at the bottom, but stays in place when you have scrolled up to review a previous entry.
